## Notes

- Two scenarios are recorded: ``dev`` (Scenario 1, first run with no cassette) and ``ci`` (Scenario 2, PR-time repeat). See `DESIGN.md` for what each measures.
- LOC counts only assertion-essential lines (no imports, no boilerplate). The benchmark uses paired `# --- benchmark assertion (LOC counted: ...) ---` markers in each test file. See DESIGN.md for the counting rule.
- LOC for execution model C is the sum of the test-side assertion block (the OTLP payload construction in `agentcore_test.py`) and the Lambda-side assertion block (`agentcore_evaluator_cdk/lambda_src/lambda_function.py`). Both move together when the assertion changes, so they are counted together. CDK / IAM / deploy-script wiring is one-time setup and is not included; see DESIGN.md "Setup LOC" for that breakdown.
- Wall time is the trimmed mean of the middle 3 runs out of 5 (single highest and lowest dropped). The full 5-run series is in the `All runs` column.
- `$ / run` is dominated by the LLM-token cost. Per-LLM-call cost is computed from the cassette token aggregates and current public list pricing (Bedrock Anthropic Claude Sonnet 4.6: $3 input / $15 output per 1M tokens; OpenAI gpt-5.4-mini: $0.75 input / $4.50 output per 1M tokens; AgentCore Evaluations custom evaluators: $1.50 per 1,000 evaluations; pricing snapshot 2026-10-19).
- C cells add one AgentCore Evaluations custom-evaluator evaluation per run ($1.50 per 1,000 = $0.0015) on top of the same-subject B cell's LLM cost. The `Evaluate` call invokes the assertion Lambda internally; Lambda invocation and CloudWatch Logs ingestion come to about $0.0000005 per call and round to zero at the table's 4-decimal display.
- agentverify's CI scenario is exactly $0 because cassette replay does not call the LLM.
- Cold-start wall time is **not** in the warm wall-time table; it lives in the "Cold-start observations" section above when recorded.
